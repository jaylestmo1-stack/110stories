## 2026-07-06 - UX Patterns for Sensitive Digital Archives
**Learning:** High-impact digital archives benefit from "README-as-UI" with "Engagement Choice" access, "Compassionate Navigation" (linking warnings to support), and high-density support resources (like 988) to reduce user distress and cognitive load.
**Action:** Use scannable, accessible interfaces with immediate, direct support pathways.

## 2026-07-15 - Archive Metadata Accessibility Row
**Learning:** Proactively informing users about accessibility features (screen-reader compatibility, searchability) in the primary metadata table reduces uncertainty and improves the "Immediate Utility" of archival assets.
**Action:** Include an "Accessibility" row in archive metadata tables for static documents.
