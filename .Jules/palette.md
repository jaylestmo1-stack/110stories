## 2025-05-08 - README-as-UI Accessibility
**Learning:** In repositories where the primary asset is a large document (like a PDF) rather than a functional web application, the README acts as the primary user interface. Providing explicit metadata (file type, size, and page count) before a user initiates a download improves the "information scent" and helps users with limited data or screen readers make informed decisions.
**Action:** Always include clear metadata for large downloadable assets in the repository's landing page or README.
