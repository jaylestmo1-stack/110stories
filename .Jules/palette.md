## 2026-06-13 - The "README-as-UI" Pattern for Static Archives
**Learning:** In repositories that are primarily static content archives (like this PDF collection), the README serves as the primary User Interface. UX success depends on emotional safety (Content Warning), predictability (Metadata like file size/pages), and "Scent of Information" (listing specific roles featured in the text).
**Action:** Always provide metadata (format, size, reading time) and qualitative discovery hooks (featured voices) for large document assets to reduce interaction cost and manage user expectations.
