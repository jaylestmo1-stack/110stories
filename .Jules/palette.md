## 2025-05-10 - Enhancing Content Discoverability in Content-Centric Repositories
**Learning:** In repositories where the primary value is an asset (like a PDF) rather than code, the `README.md` acts as the user interface. Providing descriptive metadata (format, size, page count) directly in the `README.md` reduces friction and helps users make informed decisions before downloading or opening large assets.
**Action:** Always include asset metadata and clear descriptions in the README for repositories that serve primarily as content containers.
