## 2026-03-15 to 2026-03-24 - Sensitive Archive & Research UX
**Learning:** Sensitive archives benefit from direct `tel:`/`sms:` URIs, semantic `<nav>`, platform-agnostic ARIA labels, and GitHub-native warning callouts (`[!WARNING]`). Multidisciplinary researchers benefit from immediate, copyable APA/MLA/BibTeX citations.
**Action:** Wrap warnings in callouts, use responsive helplines with descriptive ARIA, and offer copy-friendly citations.

## 2026-03-25 - Comprehensive UI Landmarks & Frictionless Citations
**Learning:** Screen readers reading links or emojis inside navigation benefit from `aria-hidden` icons and descriptive `aria-label`s. Researchers benefit immensely from `<pre><code>` code blocks for all citation styles to leverage native GitHub copy actions.
**Action:** Wrap navigation icons in `aria-hidden` spans, add explicit anchor IDs for looping/returning links, and provide pre-formatted, copy-ready blocks for APA/MLA citations.
