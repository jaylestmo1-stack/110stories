## 2025-05-22 - README-as-UI for Static Assets
**Learning:** In repositories where the primary asset is a static document (like a PDF), the README serves as the primary User Interface. Providing metadata (size, page count, estimated reading time) and navigation tips (search, bookmarks) significantly reduces friction and improves accessibility for screen reader users.
**Action:** Always include a metadata summary and a "Tips for Reading" section when the repository's value is centered on a long-form document.
