## 2025-05-16 - README-as-UI for Asset Discovery
**Learning:** For repositories where the primary asset is a single large file (like a PDF), the README serves as the primary UI. Providing metadata like file size, page count, and estimated reading time significantly improves the user experience and accessibility, helping users make informed decisions before downloading large assets.
**Action:** Always include a "Quick Facts" section and a clear, descriptive call-to-action link for the primary asset in content-focused READMEs.
