## 2026-06-01 - Scent of Information in Digital Archives

**Learning:** In content-centric repositories where the primary asset is a large document (like a PDF), the README acts as the primary user interface. Providing a "scent of information" by surfacing specific qualitative details (such as the diverse roles and perspectives featured in the document) significantly reduces the interaction cost for users before they commit to a download.

**Action:** Always look for ways to extract and display key metadata and thematic highlights from primary assets in the README to help users make informed decisions.
