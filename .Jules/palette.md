## 2025-05-23 - README as Primary User Interface
**Learning:** In repositories that primarily serve as a digital archive for a single large asset (like a PDF), the README.md effectively becomes the primary user interface. UX can be significantly improved by providing clear metadata (format, size, page count) and usage guidance (tips for reading) directly in the README, helping users make informed decisions before interacting with the asset.
**Action:** Always provide clear asset metadata and descriptive call-to-action links when the repository's value is centered around a few key files.
