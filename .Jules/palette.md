## 2025-05-29 - [Content-as-UI: The README Archive Pattern]

**Learning:** In repositories that serve as digital archives (like 110stories), the README is the primary user interface. UX can be significantly improved by implementing a "Scent of Information" pattern—listing specific qualitative details (like featured roles: firefighters, nurses, etc.)—and providing clear asset metadata (file size, page count, reading time) to reduce user interaction cost before a large download.

**Action:** When working on document-based repositories, prioritize descriptive metadata and topical previews in the README over a simple list of files.
