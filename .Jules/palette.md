## 2025-05-30 - Content-Centric README as UI
**Learning:** In repositories that are primarily digital archives (like this one with a single large PDF), the README.md acts as the entire User Interface. Standard software UX principles like "scent of information," metadata discoverability, and accessibility (content warnings) must be applied to the README text to reduce user friction and cognitive load.
**Action:** Always treat READMEs in content-focused repos as a UI: provide file metadata (size, pages), estimated reading time, thematic previews, and necessary content warnings.
