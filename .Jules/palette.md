## 2026-06-04 - README-as-UI for Static Archives
**Learning:** For repositories archiving historical documents with no traditional UI, the README acts as the primary interface. UX can be significantly improved by providing clear metadata (size, pages, reading time), a "scent of information" (previewing content), and contextual guidance (Content Warnings, Tips for Reading).
**Action:** When working on document-centric repositories, treat the README as a landing page UI. Include metadata, content previews, and clear navigation paths to major assets.
