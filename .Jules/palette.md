## 2025-05-17 - README as UI for Content Repositories
**Learning:** In repositories where the primary asset is a static document (like a PDF), the README serves as the primary User Interface. UX can be significantly improved by providing immediate context, descriptive download links, and metadata (file size, page count, reading time) to help users make informed decisions before downloading large files.
**Action:** Always treat READMEs in content-centric repos as landing pages. Use descriptive call-to-actions instead of raw filenames and provide metadata to manage user expectations.
