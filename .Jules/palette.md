## 2026-03-15 to 2026-03-25 - UX & Archival Accessibility
**Learning:** Sensitive archives benefit from direct `tel:`/`sms:` URIs, semantic `<nav>`, and copy-ready `<pre><code>` citations.
**Action:** Wrap warnings, use responsive helplines, and optimize landmark paths.
## 2026-03-26 - Compassionate Crisis Intervention
**Learning:** Distressed users benefit from immediate, explicit Call/Text choices directly within Content Warning blocks.
**Action:** Enhance warnings with direct, accessible `tel:` and `sms:` URI links.

## 2026-03-27 - Robust Scroll Anchors for Seamless Nav
**Learning:** Custom Quick Navigation links in Markdown documents can break across different GitHub/Markdown rendering engines if standard Level-2 headings rely on auto-generated slug identifiers. Placing explicit, inline HTML `<span id="...">` elements inside headings guarantees perfect deep-linking behavior.
**Action:** Wrap heading text in `<span id="...">heading text</span>` matching navigation anchors.
