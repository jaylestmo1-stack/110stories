## 2026-03-27 - README-as-UI Pattern
**Learning:** In content-centric repositories that lack a traditional interface, the README serves as the primary User Interface. UX can be significantly improved by treating the README as a landing page: providing immediate historical context, clear metadata (format, size, page count), and emotional safety features like Content Warnings for sensitive material.
**Action:** Always evaluate if the README needs to function as a UI by surfacing qualitative details ("Scent of Information") and practical metadata to reduce user interaction cost.

## 2026-03-27 - Content Warnings as Accessibility
**Learning:** For archives containing traumatic or sensitive historical content, a prominent 'Content Warning' is a critical accessibility and micro-UX feature. It provides users with the necessary agency and emotional safety to engage with the material on their own terms.
**Action:** Include clear Content Warnings at the beginning of READMEs for repositories archiving sensitive or potentially distressing content.
