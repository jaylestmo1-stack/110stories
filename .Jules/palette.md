## 2025-05-26 - [Historical Archive README UX]

**Learning:** For repositories archiving sensitive or traumatic historical content, the README serves as the primary UI. Providing immediate context, a prominent content warning, and detailed asset metadata (size, format, page count, reading time) significantly reduces cognitive load and provides emotional safety for users.

**Action:** Always include a 'Content Warning' section and 'Quick Facts' metadata when dealing with sensitive document-based archives to help users make informed decisions before interacting with the content.
