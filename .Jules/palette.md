## 2025-05-18 - README-as-UI for Content-Centric Repositories
**Learning:** In repositories where the primary asset is a large document (e.g., a PDF), the README serves as the primary User Interface. UX is significantly enhanced by providing immediate context (About section) and clear metadata (file size, page count, reading time), which helps users make informed decisions before downloading.
**Action:** Always include descriptive metadata and a human-readable call-to-action for primary assets in content-focused READMEs to improve accessibility and user predictability.
