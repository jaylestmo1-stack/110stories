## 2025-05-14 - README-as-UI for Content Repositories
**Learning:** In repositories where the primary asset is a static file (like a PDF) and there is no traditional web UI, the README becomes the primary user interface. Providing immediate context (About section) and technical metadata (file size, page count, reading time) significantly improves the user experience by reducing uncertainty before a large download.
**Action:** Always include an 'About' section for context and a detailed metadata list for primary assets in README-only repositories.
