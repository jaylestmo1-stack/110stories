## 2026-05-05 - Repository First Impression UX

**Learning:** In content-heavy repositories (like story collections), the "Empty Repo" syndrome is a major UX fail. When a user arrives and sees only a minimal README with no obvious way to access the content, they are likely to bounce. Accessibility isn't just about ARIA labels; it's about making the primary value proposition of the repo discoverable and easy to access.

**Action:** Always ensure the main project assets are linked prominently in the README with descriptive, accessible text. Avoid burying the lead.
