## 2026-07-06 - UX Patterns for Sensitive Digital Archives
**Learning:** High-impact digital archives benefit from "README-as-UI" with "Engagement Choice" access, "Compassionate Navigation" (linking warnings to support), and high-density support resources (like 988) to reduce user distress and cognitive load.
**Action:** Use scannable, accessible interfaces with immediate, direct support pathways.

## 2026-07-15 - Immediate Utility Hint
**Learning:** Providing explicit document metadata (searchability, pages, read time) directly within the primary call-to-action's ARIA label and title reduces cognitive friction, allowing users to assess the commitment and accessibility of an archival asset before interaction.
**Action:** Embed key asset metadata in download link attributes for immediate user context.

## 2026-07-10 - Visible Metadata & Shortcut Hint
**Learning:** Displaying file size and providing a search shortcut hint (Ctrl+F) in archival download links reduces interaction cost and helps users assess asset utility immediately.
**Action:** Include file size in link text and keyboard hints in title attributes for archival assets.
