## 2026-06-11 - The README-as-UI Pattern for Static Archives
**Learning:** In repositories where the primary asset is a static document (like a PDF), the `README.md` serves as the entire user interface. High-impact UX in this context means prioritizing emotional safety (Content Warning), predictability (Metadata like file size/pages), and reduced interaction cost (Scent of Information via "Themes & Perspectives").

**Action:** When working on static archives, always include immediate metadata, clear navigation (Quick Links), and topical context to humanize the data before the user commits to a download.
