## 2025-05-21 - README-as-UI Pattern for Content Archives
**Learning:** In repositories where the primary asset is a static document (like a PDF), the README serves as the primary User Interface. UX can be significantly improved by providing descriptive metadata (format, size, page count) and a human-readable "Call to Action" instead of just a filename. This reduces cognitive load and improves accessibility for screen readers.
**Action:** Always include clear metadata and descriptive download links for primary assets in content-focused repos.
