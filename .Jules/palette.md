## 2025-05-28 - README-as-UI for Content Archives
**Learning:** In repositories that primarily host static documents (like PDFs) and lack a traditional web UI, the README becomes the primary user interface. Providing metadata (file size, page count, format) and context (reading time, themes) reduces cognitive load and provides a "scent of information" that helps users decide whether to engage with the asset.
**Action:** Always treat the README as a UI in document-centric repos; include clear metadata, descriptive download links, and a "Scent of Information" section to preview content.

## 2025-05-28 - Trauma-Informed UX: Content Warnings
**Learning:** For archives containing sensitive or traumatic historical content (e.g., 9/11 narratives), a prominent content warning is a critical accessibility and micro-UX feature. It provides emotional safety and allows users to prepare themselves or opt-out before encountering potentially distressing material.
**Action:** Include a clear, high-contrast content warning at the top of the interface (or README) when dealing with sensitive historical or personal trauma archives.
