## 2025-05-20 - README-as-UI for Content Repositories
**Learning:** In repositories where the primary asset is a static document (like a PDF), the README serves as the primary User Interface. Standard UX principles like "affordance" (clear download buttons), "transparency" (file metadata like size/pages), and "guidance" (tips for usage) significantly improve the user's first interaction.
**Action:** Always provide file format, size, and consumption expectations (e.g., reading time) for primary assets in content-focused READMEs.
