## 2026-07-20 - UX Patterns for Sensitive Digital Archives
**Learning:** High-impact digital archives benefit from "README-as-UI" with "Engagement Choice" access, "Compassionate Navigation", and high-density support resources (like 988) to reduce user distress. Explicit metadata (searchability, pages, read time) within call-to-action attributes reduces cognitive friction.
**Action:** Use scannable interfaces with immediate support pathways and embedded asset metadata.

## 2026-08-01 - Visual Cues & Archival Trust
**Learning:** Visual indicators (e.g., ↗️) for new-tab links reduce user surprise. Explicit versioning and contextual metadata (Usage, Keywords) in archival tables build trust and provide an immediate audit trail for researchers and students.
**Action:** Use visual cues for external links and include versioning/contextual metadata in archival records.
